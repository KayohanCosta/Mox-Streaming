# 🚀 Mox Streaming Projeto Web

## 📌 Sobre o projeto

Este projeto é uma aplicação web moderna desenvolvida com foco em performance, escalabilidade e experiência do usuário.

## 🛠️ Tecnologias utilizadas

* Vite
* TypeScript
* React
* Tailwind CSS
* shadcn/ui

## ⚙️ Como rodar o projeto localmente

### Pré-requisitos

* Node.js instalado
* npm ou yarn

### Passos

```bash
# Clone o repositório
git clone <URL_DO_SEU_REPOSITORIO>

# Acesse a pasta do projeto
cd <NOME_DO_PROJETO>

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

O projeto estará disponível em:
http://localhost:5173
